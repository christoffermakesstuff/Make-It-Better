# Make It Better

A simple mastering plugin for Logic Pro (AU), built in C++ with JUCE.

I'm a vocal producer and audio engineer. I built this to get a release-ready
master fast, without stacking five plugins.

## What it does
- One control that adds loudness, tone and polish in a single move
- Built for vocals and full mixes

## Built with
- JUCE / C++
- Xcode
- Tested in Logic Pro
